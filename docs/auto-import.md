# Google Drive 자동 가져오기

> Route Viewer 문서 · [← README 목차로](../README.md#문서-목차)

## 주행기록 자동 가져오기 (Google Drive 동기화 폴더)

운전자가 Google Drive 공유 폴더에 올린 주행기록 엑셀을, 이 PC 의 **Google Drive 데스크톱 앱이 동기화한 로컬 폴더**에서
읽어 기존 기록에 자동으로 추가합니다. 앱은 Drive 웹 주소에 접속하지 않고 서버도 필요 없습니다(데스크톱 앱 전용).

```
운전자 휴대폰 ──(Google Drive 앱으로 업로드)──▶ Google Drive 공유 폴더
                                                     │ (Drive 데스크톱 앱이 PC로 동기화)
                                                     ▼
                                    Route Viewer PC  G:\…\주행기록  ◀── 60초마다 확인
```

Google Drive **데스크톱 앱은 Route Viewer 를 실행하는 PC 한 대에만** 설치하면 됩니다. 운전자는 휴대폰만 있으면 됩니다.

### 운전자 (휴대폰)
1. 휴대폰에 **Google Drive 앱**을 설치합니다(안드로이드는 대개 기본 설치).
2. 관리자가 공유 폴더를 운전자 Google 계정에 **편집자(공유 드라이브는 콘텐츠 관리자)** 권한으로 공유합니다.
3. 매일 nav-app 에서 받은 주행기록 엑셀을 공유 폴더에 올립니다(카톡으로 보내던 파일 그대로).
   - Drive 앱에서 공유 폴더 열기 → **＋ › 업로드** → 엑셀 선택, 또는
   - 파일 앱·다운로드에서 엑셀 길게 누르기 → **공유 › Drive** → 공유 폴더 선택
   - 파일 이름은 자유입니다. 같은 파일을 두 번 올려도 다시 넣지 않습니다.

### 처음 연결하기 (Route Viewer PC, 한 번만)
1. [Google Drive 데스크톱 앱](https://www.google.com/drive/download/)을 설치하고 공유 폴더 권한이 있는 계정으로 로그인합니다.
2. 파일 탐색기에서 Drive 드라이브(보통 `G:`)를 열어 주행기록 폴더가 보이는지 확인합니다.
   - 공유 드라이브: `G:\공유 드라이브\<드라이브 이름>\…`
   - 나와 공유됨 폴더: drive.google.com 에서 폴더 우클릭 → **정리 › 바로가기 추가**로 내 드라이브에 바로가기를 만들면
     `G:\내 드라이브\<폴더 이름>` 으로 보입니다.
   - (권장) 그 폴더 우클릭 → **오프라인 사용 가능**으로 두면 파일을 미리 내려받아 두어 확인이 빠릅니다. 스트리밍 모드여도 동작합니다.
3. Route Viewer › **데이터 관리 › 주행기록 자동 가져오기 › 폴더 선택**에서 위 폴더를 고릅니다. (웹 주소 `https://drive.google.com/...`는 받지 않습니다.)
4. 대상 파일 수가 나오면 **전체 가져오기**(과거 파일까지) 또는 **지금부터 새 파일만**을 고릅니다. 나중에 "건너뛴 파일 가져오기"도 할 수 있습니다.

### 동작
- 앱 시작 시 한 번, 실행 중에는 60초마다 폴더를 확인합니다(파일 감시 이벤트에 의존하지 않는 주기적 스캔 — 가상 드라이브에서도 동작).
  [지금 확인]으로 바로 확인할 수 있고, ON/OFF·폴더·처리 이력은 앱을 다시 켜도 유지됩니다.
- 하위 폴더 포함 `.xlsx` `.xls` `.csv`, Excel 임시 파일(`~$…`)·숨김 파일 제외.
- 동기화 중인 파일은 크기·수정 시각이 멈춘 뒤 읽고, 읽는 동안 바뀌면 다음 확인 때 다시 봅니다. 읽기 실패(잠김 등)는 다음 확인 때 자동 재시도.
- 파일 내용 지문(SHA-1, 수동 불러오기와 같은 값)으로 **같은 내용은 이름·경로가 바뀌어도 다시 넣지 않습니다** — 예전에 수동으로 넣은 파일 포함.
  내용이 바뀐 파일은 다시 병합하되 기존 기록은 지우지 않습니다(레코드 중복 제거는 수동 불러오기와 동일).
- 저장 전 확인 팝업은 띄우지 않습니다. 자동으로 들어온 파일은 이슈 없음(확인)으로 보이지 않고 **"자동 · 검토 전"**으로 표시되며,
  데이터 관리·일자 요약에서 이슈 등록 또는 [검토 완료(이슈 없음)]을 누르면 해제됩니다.
- 원본 파일은 읽기만 합니다. 폴더에서 파일이 사라져도 DB 기록은 지우지 않고 "폴더에 없음"만 표시합니다.
- 폴더에 접근할 수 없으면(Drive 앱 종료·로그아웃 등) 기존 기록은 그대로 두고 상태만 표시합니다.
- 처리 패널과 달력 맨 위에 **"Google Drive 2026년 10월 2일 주행분까지 가져왔어요"**처럼 가져온 마지막 주행 날짜, 마지막 새 파일 시각, 마지막 확인 시각을 보여줍니다.
- 처리 현황: "새 파일 3개 반영 / 이미 처리 2개 / 실패 1개", 파일별 원본 이름·가져온 시각·날짜·차량·추가/중복·실패 사유, 실패 파일 다시 시도.
