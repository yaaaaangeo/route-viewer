# Route Viewer (경로 뷰어) v3.1.2

nav-app 주행기록(.xlsx/.csv)을 **로컬 데이터베이스에 계속 쌓아두고** 달력 · 누적 지도 ·
Coverage · 통계 · GPS 리플레이로 보는 데이터 관리/분석 도구입니다.

- 버전: `package.json` 기준 **3.1.2** (화면 좌측 하단 배지 `APP_VERSION`도 v3.1.2)
- 저장소: 데스크톱 앱 = **SQLite**, 브라우저로 열면 = **IndexedDB** (화면 코드는 같은 `RouteDB` 인터페이스만 씀)

---

## 빠른 시작

- **설치해서 쓰기** — `release\RouteViewer-<버전>-win-x64.exe` 실행 → [설치 · 실행 · 빌드 · 테스트](docs/install-build-test.md)
- **고친 코드 바로 실행(개발)** — VS Code 터미널에서 `.\run` (또는 바탕화면 "Route Viewer (최신)")
- **Google Drive 연동** — 데이터 관리 › 주행기록 자동 가져오기 → [Google Drive 자동 가져오기](docs/auto-import.md)

## 주요 기능

- **파일 불러오기는 "추가(merge)"** — 새 파일을 넣어도 기존 날짜 기록은 지워지지 않습니다.
  중복 판정 키는 `date | time | vehicle | lat(소수점 6자리) | lng(소수점 6자리)`이고,
  같은 키인데 `place/road/weather/timeOfDay/traffic/speed` 값이 다르면 "충돌"로 따로 집계합니다.
- **Import History** — 파일별 원본/추가/중복/충돌 건수, 대표 차량·거리, 불러온 사람, 충돌 상세.
- **Import 이슈 기록 · 이슈 데이터 분리** — 파일을 저장하기 전에 "이 파일에 이슈가 있나요?"를 파일별로 묻고,
  이슈로 표시한 파일에서 온 GPS 기록을 달력·누적 지도·Coverage·통계·추천에서 **데이터 상태 필터**
  (전체 / 이슈 없음 / 이슈만)로 함께 걸러 볼 수 있습니다. 누적 지도의 이슈 칸과 통계 막대의 이슈 몫은
  **회색**으로 그려서 한눈에 구분됩니다.
- **전체 데이터 수집 현황** — 달력 맨 위 표에 KPI·제안 목표 대비 누적 주행 시간·수집 시간과 진행률.
- **달력 · 일자 요약** — 달력 칸마다 그 날의 수집·주행 시간, 날짜를 열면 운행 시간·구역·차량·주행 거리·기록 수·
  주행 시간(첫~마지막 기록)·수집 시간(GPS 실제 기록)·GPS 공백/점프, **교통 시간대 · 조도 조건 분포(분 · 기록 수)와
  조건 조합**.
- **교통 시간대 · 조도 조건** — 한 기록이 교통 시간대(출근·점심·퇴근 등)와 조도 조건(주간·일출·일몰·야간)을 따로
  동시에 가집니다. 요일(평일/주말)·날씨와 함께 `평일 · 퇴근 피크 · 일몰 전후 · 비` 같은 복합 조건으로 집계합니다.
- **누적 지도** — 전체 또는 선택한 날짜 범위 기록의 밀도 지도 + 구역별 **Coverage Map**,
  현재 지도 **PNG 캡처**(데스크톱 앱·브라우저 모드).
- **통계** — 지역별/차량별 분포, 교통 시간대·조도 조건·평일/주말별 수집 시간과 기록 수, 구역·차량별 시간대 표.
- **추천 주행** — 부족한 구역·요일·교통 시간대·조도·날씨 조합을 통계로 찾아 점수·근거·권장 시간·추가 횟수까지 제시합니다
  (예상 Edge Case 는 가능성 추정, LLM 미연결). 탭 맨 위 **오늘 추천 주행 Top 3** 가 운전 전에 볼 "어디 · 언제 · 왜"만
  보여주고, 점수·근거·Coverage·Maneuver 같은 기존 분석은 **상세 분석 보기** 안에 그대로 있습니다.
- **주행 계획** — "오늘 8시부터 나가면?" 처럼 **운행 시간을 바꿔 보고** 그 시간에 어디부터 어떻게 돌지를
  시각 블록으로 받아봅니다. 구역 간 이동은 HD Map 도로망 최단 거리로 잡고(안 되면 직선 거리), 블록마다
  구역을 오가지 않도록 구역 변경 비용을 둡니다. 지금 운행 시간(기본 09:00~18:00)과 비교해서 무엇이 새로 잡히는지도 보여줍니다.
- **자동 분석 추천** — 상위 구역만 고르면 **도로망을 스스로 구간으로 나누고 세부 구역을 만들어** 추천합니다.
  세부 구역을 직접 그릴 필요가 없습니다(수동 등록은 보정용). 추천은 `강남 → 테헤란로 동측 구간 #2 →
  평일 퇴근 피크 · 일몰 전후 · 동쪽 방향 2회` 수준이고, 지도에 구간·시작/끝·우선순위 색으로 표시됩니다.
  지도 POI(OSM)를 받으면 학교 인접·업무 밀집 같은 시설 기반 분류도 합니다(없으면 GPS·HD Map 만으로).
- **HD Map 우선 수집 정책(Priority Policy)** — "이번 달은 ⑩ 중심" 같은 사업 요청을 **코드 수정 없이 설정에서**
  날짜별 정책으로 바꿉니다. 추천 점수(사업 우선도) · 설정 탭 ①~⑫ 배지 · 통계 "정책 우선지역" 비교가 모두 같은
  활성 정책을 씁니다. 지난 정책은 지우지 않고 보존합니다.
- **설정** — 접근 권한(들어올 수 있는 이름 명단 추가·해제, 최소 1명 · 내 이름을 빼면 바로 로그아웃 · 비밀번호 아님),
  차량/지역 추가·비활성화(삭제 아님), HD Map 우선 수집 정책, Coverage Depth 등급 기준, 교통 시간대 시각,
  일출·일몰 전후 범위.
- **데이터 관리** — 날짜별/전체 삭제(삭제는 여기서만), 주행기록 자동 가져오기(동기화 폴더), 서버 동기화 설정.
- **백업/복구** — 병합 복구(기본) / 전체 교체 복구(주행 기록만 교체, 설정·수동 셀은 지우지 않음).
